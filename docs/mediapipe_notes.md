# MediaPipe Hands Notes

MediaPipe detects 21 hand landmarks.

Each landmark contains:
- x coordinate
- y coordinate
- z coordinate

Important landmarks:
0 = Wrist
4 = Thumb Tip
8 = Index Tip
12 = Middle Tip
16 = Ring Tip
20 = Pinky Tip

Output format:
(x, y, z)

MediaPipe successfully tested on webcam.
